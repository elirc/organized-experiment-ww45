# Mission Learning Path

This suite is a training campaign for Knowledge Hub. You are not just reading code; you are tracing entry points, annotating flows, predicting failures, and checking your answers against source-backed rubrics.

Recommended pacing: do one or two junior missions per session, one mid-level mission per session, and one senior mission per longer study block. Always open the named files and line ranges before answering.

Self-grade by asking: did I name the source file, line range, owner of the logic, trust boundary, and likely failure mode?

This suite uses the real app: a Next.js, Prisma, PostgreSQL, Zod, React Query internal knowledge base described in `README.md:1-20`.
