# Architectural Cartographer

This suite is a top-down guide to Knowledge Hub: an internal knowledge base where users sign in, search published entries, and where editors/admins manage drafts, publication, archival, and curation. The app purpose and stack are stated in `README.md:1-20`; the runtime scripts are in `package.json:5-16`.

Use the files in this order:

1. `00-reading-map.md` for the mental model and first files to open.
2. `01-junior-engineer.md` for setup, folders, entry points, component anatomy, route anatomy, and glossary.
3. `02-mid-level-engineer.md` for contracts, state, API flow, and diff-reading practice.
4. `03-senior-engineer.md` for critique, audits, testing gaps, and ownership planning.
5. `04-reference-suite.md` when you are actively changing or reviewing the code.

Checkpoints are self-contained. Answer them out loud or in notes, then immediately compare against the "How to self-grade" sections. A strong answer cites files and line ranges the way a production code review would.
